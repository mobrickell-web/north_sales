# my-landing-page

Next.js landing-page frontend starter: App Router, Tailwind v4, shadcn/ui, typography tokens, TanStack Query, and Zod + React Hook Form.

## Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Architecture

See [docs/FLOW.md](docs/FLOW.md) for folder layout, render flow, and how to add sections or forms.

## Scripts

```bash
npm run dev
npm run lint
npm run build
```
